# More GPS trace examples

Observed prefixes from the repository's dataset demo trips. Each point is [longitude, latitude], with 15 seconds between points. Paste a JSON block into the Single trip trace box.

These are demonstration examples, not independent validation data: historical lookup tables may include their source trips.

## Example 1: 8 points, 105 seconds observed

Start timestamp: `1375372754` (Unix seconds). Call type: `B`. Taxi ID: `20000403`. Taxi stand: `10`.
